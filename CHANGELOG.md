# Changelog

## 1.0.0

- Production multi-user architecture.
- PostgreSQL central database.
- Email/password authentication with server-side sessions.
- TOTP multi-factor authentication and single-use recovery codes.
- Six server-enforced roles.
- Controlled journey workflow.
- High-risk two-stage approval.
- Vehicle and driver compliance validation.
- Resource conflict detection.
- Mandatory risk assessment and checklist.
- Dynamic check-in intervals and overdue background monitoring.
- In-app notifications.
- Permanent audit logging.
- Admin user and password management.
- CSV and JSON exports.
- PWA frontend using the Moveintrack identity.
- Docker Compose deployment with automatic HTTPS proxy.
- Backup and restore scripts.
